Шаги по выполнению задания

Есть два проекта, которые нам необходимо будет запаковать в Docker-образ и настроить запуск приложений:

    Проект, который собирается при помощи CMake
    Простое приложение на Flask

    Склонируйте репозиторий: https://gitlab.akhcheck.ru/task-templates/docker-template
    Переключитесь на ветку task-docker.
    Скопируйте task-docker в ваш проект.
    Создайте Dockerfile в папке task-docker/cmake-with-flask со следующими шагами для контейнера:
        (1 point) В папке / должен быть файл README.md
        (1 point) В папке /bin должен быть исполняемый файл ./print_hello, который печатает “Hello world” и ничего больше не делает
        (1 point) git должен быть установлен внутри контейнера.
        (2 point) Внутри проекта проект на cmake должен быть собран. Команды для сборки проекта на cmake: mkdir build && cd build && cmake .. && make. Команда для запуска процесса должна быть bin/C
        (2 points) Пользователь ‘devops2024user’ должен быть создан, при этом контейнер должен запускаться из-под этого пользователя. Это позволит избежать проблем при запуске приложения.
        (3 points) Приложение на Flask должно быть запущено при старте контейнера (система ожидает, что приложение запущено на порту 8898). Чтобы узнать опции запуска проекта, выполните команду python3 app.py --help.

Требования

    Используйте приватный репозиторий на Gitlab-е, при помощи которого вы сдали задание 0. Не забудьте проверить, что в коллабораторах есть checker.
    В приватном репозитории создайте ветку task-docker, в нем создайте папку task-docker.
    Положите созданный и работающий проект в папку task-docker в ветке task-docker.
    Создайте Merge Request из ветки task-docker в ветку main/master, добавьте проверяющего в Merge Request и не сливайте этот Merge Request!
    Необходимо добавить утилиту which: она будет использована для проверки наличия git.
